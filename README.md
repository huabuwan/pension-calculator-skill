# 养老金测算 Skill

一个本地运行的 WorkBuddy 技能：通过对话采集（或上传权益单解析）用户的社保缴纳信息，按政策口径生成一份**带参数、可调整的养老金测算 Excel 工作簿**（缴纳明细含预估待缴纳、退休金预估到 99 岁、测算说明页）。

> 本技能**不含任何预置个人数据**，每次使用都从本次对话的用户输入重新采集信息。示例数据均为虚构，仅供演示格式。

## 功能

- 采集退休地、退休年龄、多段缴纳历史（起止年月 / 城市 / 类型 / 基数或累计额），或解析上传的养老权益单。
- 内置各地社平工资缓存（13 城、2006–2033 逐年补全：北京/上海/四川为官方实际序列；其余城市锚点年为官方值，其余年份按约 5%（历史）/ 2%（未来）估算。生成测算表时 2024 年起一律按「社平增幅」参数活公式推算，与缓存展示值无关）。
- 生成工作簿三张表：
  1. **测算说明** —— 计算规则、政策依据、参数含义、数据来源与免责；
  2. **缴纳明细** —— 顶部黄色参数区（可改）+ 逐年记录（橙色「预估待缴」行）+ 底部「退休首年计算结果」；
  3. **退休金预估** —— 从退休年起逐年（到 99 岁）月/年养老金与累计领取。
- 默认直接输出**计算好的数值**，任意查看器打开即见正确数字（不会出现活公式未计算显示 0、或公式描述显示 #NAME? 的问题）。

## 安装

将本目录放入 WorkBuddy 用户级 skills 目录即可：

```
~/.workbuddy/skills/养老金测算/
```

包含：`SKILL.md`（流程与规则）、`scripts/build_pension.py`（生成脚本）、`data/社平工资表.xlsx`（社平缓存）、`inputs.example.json`（虚构示例）、`README.md`、`LICENSE`。

## 使用流程（由 Skill 驱动，无需手动跑脚本）

1. 与 Skill 对话，**按提示逐项提供**退休地、退休年龄、各段缴纳信息（或上传权益单）。Skill 会主动询问所有必要信息，不会沿用任何历史数据。
2. Skill 写 `inputs.json` 并运行生成脚本，产出 `养老金测算_<退休地>.xlsx`。
3. 打开表格，按需修改黄色参数单元格；如需 Excel 内改参数即时重算，可在 `inputs.json` 设 `"output_mode":"formula"` 后重跑。

## 计算规则（核心口径）

- **指数分母统一用「待遇领取地社平」**：跨省归集退休时，缴费工资指数 = 本人各参保地缴费工资 ÷ 待遇领取地对应年度社平（人社部 2009 转移接续意见第二条）。
- 平均指数 = Σ(月缴费指数×月数) ÷ 总月数；指数化工资 = 退休时社平 × 平均指数。
- 基础养老金 = (退休时社平 + 指数化工资) ÷ 2 × 缴费年限(年) × 1%。
- 个人账户养老金 = 个账累计 ÷ 计发月数（55→170、60→139、50→195、65→101）。
- 灵活就业缴 20%，其中 8% 进个人账户。
- 指数封顶 3.0：默认**不封顶**；跨省到较低社平城市退休时可手动改 TRUE。
- 终身领取：退休后月养老金按「养老增幅」逐年复利，累计逐年累加。

## 输入契约（inputs.json 示例，虚构数据）

```json
{
  "retire_city": "北京",
  "retire_age": 60,
  "retire_year": 2040,
  "manual_sheping": {},
  "params": {"sheping_growth":0.02,"pension_growth":0.02,"interest_rate":0.025,"flex_ratio":0.60,"cap_index":false},
  "years": [
    {"year":2010,"city":"上海","type":"单位职工","months":12,"base_monthly":9000,"rate":0.03,"is_estimated":false},
    {"year":2040,"city":"北京灵活","type":"灵活就业","months":12,"is_estimated":true}
  ]
}
```

- `retire_city` / `retire_age` / `retire_year` 为**必填**。
- `years` 与 `segments` 二选一；推荐 `years`（归一化后最灵活）。
- 某年只知「个人账户年入账 `account_entry`」不知月基数：脚本反推 `月基数 = account_entry/(0.08×月数)`。
- 预估段 `is_estimated:true`：不填 `base_monthly`，脚本用 `当年待遇领取地社平 × 灵活档位` 计算；若指定具体基数则填 `base_monthly` 优先。
- `manual_sheping`：缓存缺城市时按 `{"城市":{"年份":月社平}}` 补充。

完整样例见 [`inputs.example.json`](inputs.example.json)（含 `years`、`segments`、`account_entry`、预估段、`manual_sheping` 五种写法）。

## 隐私与分发说明

- 权益单含姓名/身份证号等敏感信息，上传前请自行脱敏；本工具本地处理、不上传。
- **发布或分享本技能时，目录内只能包含 `SKILL.md` / `README.md` / `LICENSE` / `scripts/` / `data/` / `inputs.example.json`（虚构示例）**，切勿把含真实数据的 `inputs.json` 或个人权益单打进包。

## 数据来源与免责

社平工资来自内置缓存（13 城、2006–2033 补全）：北京/上海/四川为官方实际序列，其余城市锚点年为官方值、其他年份为估算（历史约 5%、未来约 2%）。生成测算表时 2024 年及以后一律按「社平增幅」参数活公式推算，与缓存展示值无关。**缓存为通用参考，可能与本人社保局系统精确值有出入，请以参保地社保局公布值为准**，并可在表中直接修改对应年份社平。本工具为个人规划辅助，非官方核算结果。
